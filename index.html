01. Infrastructure Monitoring

03. WAN & SD-WAN Operations

Monitor Cisco SD-WAN environments using vManage. Investigate branch connectivity issues, WAN link status, MPLS connectivity, cEdge devices and primary/secondary broadband link conditions.

04. Broadband & DIA Support

Monitor broadband and Dedicated Internet Access links, investigate link flapping, high packet loss and connectivity degradation. Track ISP-related issues and coordinate with service providers.

05. DNS & DHCP Operations

Handle DNS and DHCP-related operational requests, perform nslookup and IP verification, investigate hostname resolution issues and coordinate DNS record updates and related troubleshooting.

06. Windows Server Support

Monitor Windows server availability, perform authorized server reboots and restarts, investigate basic operating system issues and coordinate server-related incidents with support teams.

07. Linux & Unix Support

Perform basic Linux and Unix operational checks, investigate filesystem utilization, check available disk space, assist with file cleanup activities and support SSH key update requests.

08. Active Directory Support

Handle user account-related operational requests, including password unlocks, account lock/unlock activities and basic access-related support through authorized procedures.

09. Server Maintenance & Patching

Support scheduled monthly Windows and SQL patching activities across Production, Non-Production and QV environments. Monitor maintenance activities and coordinate with relevant teams.

10. Application Monitoring

Monitor application availability and performance, investigate application-related alerts and coordinate with application support teams to identify potential service impacts.

11. Enterprise Monitoring Tools

Work with ServiceNow ITOM, Dynatrace, ScienceLogic, Moogsoft, ELK basics and Vynamic View for infrastructure monitoring, alert investigation and operational visibility.

12. Incident Management

Support P1/P2 incident management activities, participate in bridge calls, coordinate with incident managers and technical support groups, provide status updates and track incident progress.

13. Alert Management

Investigate ITOM-generated alerts, verify Dynatrace auto-clear conditions, assess potential service impact, create or update incidents and route issues to the appropriate support groups.

14. ISP & Vendor Coordination

15. Escalation & SLA Management

16. Production Operations

Support production operations through operational request handling, change coordination, VMware-related support, Jenkins-related operational exposure, documentation and coordination across technical teams to maintain service continuity.
